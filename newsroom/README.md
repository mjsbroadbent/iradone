# IradOne site build

The static site for iradone.com, published with GitHub Pages. News stories arrive as JSON files in `news/data/`
(they are written and committed from elsewhere); `newsroom/build.py` turns them, and the programme data, into pages.

## Building

```
python newsroom/build.py          # rebuild every generated page from news/data/ and the JSON data files
```

`build.py` writes the article pages, the `news/index.html` archive, `news/index.json`, `news/feed.xml`,
`sitemap.xml`, the section and tag pages, the ticker and Top Stories on the homepage (between the
`<!-- NEWS:... -->` markers in `index.html`), and the programme, radio and sport pages (`pages.py`).
Only `site_url` in `newsroom/config.json` is read.

| To change | Edit |
|---|---|
| Page layout | `templates/page.html`, then `python newsroom/build.py` |
| Remove a story | delete its file in `news/data/`, then run the build |
| Fix a story | edit its file in `news/data/`, then run the build |
| Old ticker lines | `legacy_ticker.json` |
| Photo credits | `photos/credits.json` |

Photo candidates from Wikimedia Commons: Actions > Find photo candidates (`newsroom/photos.py`, briefs in
`newsroom/photo_briefs.json`) commits them to the `photo-candidates` branch.

## TV schedule

The Program Schedule on the homepage is built in the browser by `schedule.js` from `schedule.json`. Every visitor sees the same schedule for a date, because films, episodes and topics are picked by a random generator seeded with the date. Times are Irad Time; the broadcast day runs 05:00 to 05:00. The guide shows today and the next six days and marks the programme on now.

What's in `schedule.json`:

- **shows**: every programme's title, optional Iradi `subtitle`, description and optional `detail`, the line shown in blue:
  - `pool`: a daily pick from a list in `pools` (guests, topics, dishes)
  - `series`: episodes from a list, advancing each time it airs (`start` date, weekdays in `every`)
  - `serial`: numbered episodes of a daily drama, with a one-line synopsis
  - `film`: a film from `films`, seven different ones each week
  - `headline` / `headline_or_pool`: ties into the latest IradOne news story
- **grids**: the weekday, Saturday and Sunday line-ups. A slot is `{"t": "19:30", "show": "kuda"}`, or `by_day` for a different show each weekday, or `{"show": "pitch_talk", "months": [3, ...], "else": "hippodrome_weekly"}` for seasonal ones (the Irad League runs March to November).
- **specials**: dated overrides (`"date": "08-24"` yearly, `"2027-11-02"` once), Easter-relative (`"easter": -3`), the nth weekday of a month, or the first weekday after a date. Each replaces the normal programmes in its time range.

To add a show: add it under `shows`, then put its id into a grid or a special.

## Other sections

Everything below is generated by `python newsroom/build.py` (run on every publish), or filled in in the browser.

| Section | Pages | Edit |
|---|---|---|
| News sections and topics | `news/section/*.html`, `news/tag/*.html` | Made from each story's `category` and `tags` |
| Programme pages | `shows/<id>.html`, `shows/index.html` (A–Z) | `schedule.json`: each show's `genre`, `desc`, `subtitle`, `detail`. The "Coming up" list is worked out in the browser |
| Radio Irad | `radio/index.html` | `radio.json` (same format as `schedule.json`); frequencies in `newsroom/pages.py` |
| Sport | `sport/index.html` | `sport.json`: teams, conferences, grounds and strengths for ulak tartysh; race names, horse name parts, jockeys, trainers and owners; Irad League clubs; the equestrian calendar. `sport.js` plays every result from the date, so everyone sees the same results and they never change once played. The TV and radio guides use it for "Tonight: ..." lines |
| Notices and passes | Homepage panel | `notices.json`: dated notices, and the passes with the real-world point whose forecast drives each one |
| Ads | Homepage, articles, sport | Put images in `ads/` and list them in `ads.json`. Sizes: `leaderboard` (728x90) and `box` (300x250). Empty slots stay hidden |
